# Demo data

Generated by `packages/seed` — fictional names only, in the **legacy BigQuery table layout**, so the
same ingestion SQL runs on demo and live data.

```bash
npm run seed:generate -- 2026-09-23   # reproducible "as of" date (default: today)
npm run seed:inspect                  # coverage report
npm run seed:mongo                    # load MongoDB (uses the JS port of the ingestion SQL)
npm run seed:bigquery                 # load BigQuery source tables (needs GCP credentials)
```

## Volume

~1,000 catalog rows (570 in scope), ~340 accounts in 7 channels, ~500k sales rows, ~19k order lines,
~64k title × account rows, ~7k seeded estimates with ~22k history events.

## Rules covered

| Rule | Covered by |
|---|---|
| Scope: Spring/Fall ≥ 2025, HC/PB/BB | backlist 2021–2024, ebook editions (EB), ARC, Catalog, Floor Display, blank imprint, Summer season |
| Initial orders = pre-pub gross sales + open orders | shipped orders (sales), open orders, deleted, cancelled (past) and future-cancel orders |
| No double counting of invoiced orders | ~30% of shipped orders also appear in the order file + `DTL_HBG_FINAL` |
| Popular accounts | 14 accounts get zero rows on every current title |
| ReaderLink chains (org 90001368) | 10 chains, placeholder rows + POS for published titles |
| Account-level channels | MASSMER, RETINDEP with many accounts per organization |
| "Not Defined" channel, no organization | 3 accounts with no channel, 1 with no organization |
| Id + name identity | one account number reused under a different name |
| Comparable titles | ~330 titles have a comp (mostly backlist); comp-only accounts on most of them |
| Roll-up precedence | account-, org- and channel-level estimates; org and channel overrides; org estimate with no accounts |
| Stats | BookScan (~35% of current titles), eBook sales, LTD |
| Missing dates | ~10% blank paper cut-off / LDC |
| Future titles | Fall 2027 titles with few or no orders yet |
